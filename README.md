# Baker's Math

[View live](https://dkarakop.github.io/bakers-math.git/)

**Bakers'Math** is a simple web application designed for bread lovers who want to make their own bread with precise ingredient calculations. This app helps you calculate the necessary amounts of the four essential bread ingredients: flour, water, salt, and sourdough starter.

## Features

-   **Flexible Calculation:** Users can input the amount of flour or adjust the percentages of water, salt, and sourdough starter, and the app will calculate the corresponding amounts for the other ingredients.
-   **Suggested Recipe:** If you don’t have a recipe in mind, the app provides a suggested bread recipe upon loading the page.
-   **Interactive Interface:** Simple and intuitive interface built with HTML5, Sass, CSS, and JavaScript.
-   **JavaScript Classes:** This project utilizes JavaScript classes to manage the calculation logic and UI interactions.

## Technologies Used

-   **HTML5:** For structuring the content of the web app.
-   **Sass/CSS:** For styling the application with a focus on maintainability and scalability.
-   **JavaScript (ES6):** For implementing the core functionality, including class-based calculations.

## Usage

1. **Input Flour Amount:** Start by entering the amount of flour you want to use in grams.
2. **Adjust Percentages:** Modify the percentages for water, salt, and sourdough starter as needed.
3. **Calculate:** Click the "Calculate" button to get the exact amounts of each ingredient.
4. **Use Suggested Recipe:** If you're unsure where to start, use the suggested recipe that appears when the page loads.

## Project Motivation

Being a bread lover, I wanted to create a tool that would make it easier for others to bake their own bread at home. This project was also an opportunity to explore and play with JavaScript classes, enhancing both my baking and coding skills.

## Installation

If you wish to run this project locally:

1. Clone the repository:
    ```bash
    git clone https://github.com/dkarakop/bakers-math
    ```
2. Navigate to the project directory:
    ```bash
    cd bakers-math
    ```
3. Open `index.html` in your preferred web browser.
